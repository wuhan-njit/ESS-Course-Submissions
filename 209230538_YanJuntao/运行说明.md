任务三采用目标 C，固定容量及网络模型参数沿用原程序。

## 运行环境

- MATLAB R2024a-R2026a、Optimization Toolbox、MATPOWER、YALMIP。
- 将 ESS-Course-Materials 的 `interactive/` 和 `cases/` 添加到 MATLAB 路径。
- 任务三优先使用 MOSEK/Gurobi；若未安装，则使用 `solver_support/` 中的 Clarabel 接口，通过连续锥松弛的对偶下界与整数可行解上界核验；需要时对充放电状态进行分支定界。
- Clarabel 接口依赖 Python、SciPy 和 Clarabel，可用 `python3 -m pip install scipy clarabel` 安装。Windows 可改用 `python` 命令。
- 如果 MATLAB 找不到所需 Python，可执行 `setenv('ESS_PYTHON','Python 可执行文件的完整路径')` 后运行任务三。

## 文件说明

- 三个任务各有同名 MLX 与 M 文件。
- PNG 为白底 600 dpi，PDF 为 MATLAB 矢量导出，FIG 保存原始绘图对象。
- `Task3_C_raw.mat` 保存本次 C 计算的完整运行量、约束检查与最优性核验数据。
- `result_summary.mat` 汇总三个任务，任务三包含本次重新计算的数据。
- 任务三最后一节自动计算同场景 A/B/C 对比；也可在任务三运行后单独调用 `YanJuntao_209230538_Week1_ABCComparison`。
- `Task3_A_raw.mat`、`Task3_B_raw.mat` 保存比较计算的完整结果；`Task3_ABC_Comparison.csv` 为三目标数值表，`Fig_Task3_ABC_Comparison` 为配套原生图。
- 报告为 `YanJuntao_209230538_Report.pdf`。
